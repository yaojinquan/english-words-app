# 英语单词学习卡 · 外研版 Join In（三年级起点）

小学英语单词在线学习网页，配套**外研版《英语》Join In（三年级起点）**。每个词条含音标、释义、例句，单词 / 中文释义 / 英文例句 / 中文例句均可点击朗读。

在线访问：https://yaojinquan.github.io/english-words-app/

## 功能

- 顶部切换课本，切换偏好本地记忆，下次打开自动回到上次那一册
- 按单元折叠浏览，支持"全部展开 / 全部收起"
- 每个词条支持四处点读：单词（英）、释义（中）、英文例句、中文例句
- "▶ 连播本单元"自动朗读当前单元全部内容，并高亮跟随
- 朗读速度三档：慢速 / 正常 / 快速
- 一键搜索（当前册内过滤单词、中文、例句）
- 发音方案：在线发音音频优先（手机微信内置浏览器可用）+ 浏览器 TTS 兜底

## 文件结构

- `index.html` — 主页面（在线版入口）
- `books/book-gX-Y.js` — 各册单词数据
- `standalone.html` — 单文件离线版（数据已内联，双击即用，无需联网）

## 使用提示

手机上建议用 Safari / Chrome 打开；微信里直接点开也能朗读。若没有声音，先调高音量、关掉 iPhone 侧边静音开关，再点页面上的「🔊 试听」自查。朗读需要联网获取发音。
